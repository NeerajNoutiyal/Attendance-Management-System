# AttendFlow — User Manual

## 1. Introduction

AttendFlow is a web-based Attendance Management System designed to organize student records and simplify attendance tracking.

## 2. Starting the Application

1. Open the project in VS Code or GitHub Codespaces.
2. Install the dependencies using `pip install -r requirements.txt`.
3. Configure the required environment variables.
4. Run the application using `python app.py`.
5. Open the local URL displayed in the terminal.

## 3. Login

1. Open the login page.
2. Enter your authorized login credentials.
3. Submit the form.
4. If login fails, check your credentials and contact the administrator if necessary.

## 4. Managing Student Records

Authorized administrators or teachers can use the available student-management features to add, view, edit, and delete records.

Check the displayed student details before saving changes.

## 5. Marking Attendance

1. Log in with an authorized account.
2. Open the attendance section.
3. Select the available student or attendance options.
4. Submit the attendance record.
5. Verify the saved record.

Use only the attendance options actually available in the application.

## 6. Reports and Export

Open the relevant report page to review attendance records. If export is available, use the export feature to download the records.

## 7. Troubleshooting

- **Application will not start:** Check dependencies and required environment variables.
- **Login fails:** Verify the username and password.
- **Page displays an error:** Check the terminal for the Flask error message.
- **Records are missing:** Verify the selected student, date, and database.

## 8. Security

Never share passwords or secret keys. Use authorized accounts and protect attendance data.

## 9. Support

For project-related questions, review the repository README or contact the project developer.
